# Glossary

Canonical terms for the toolboxmd fork. Names follow the Lightbringer series
by Brent Weeks, the source of the company name.

| Term           | Meaning                                                                                                                                                                                                        | Avoid                                   |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------- |
| Luxin          | The company; also the work agents produce (code, PRs).                                                                                                                                                         |                                         |
| Chromeria      | This app and everything built from this fork, including its server on any machine: the gateway where the user directs every agent across harnesses, with more interfaces (such as the OpenBot mode) over time. | T3 Code Fork, Bridge, T3 (for our code) |
| Promachos      | The one bot the user talks to: a colleague with its own personality who works across every Satrapy, does work itself and hands larger chunks to Drafters through Prism.                                        | bot, assistant, Blackguard              |
| Promachos home | The Promachos's own repo and Chromeria project. It holds the persona the Promachos edits as it learns, and its conversations run there.                                                                        | bot home                                |
| Satrapy        | One area of the user's work, such as a business or a product line, kept in its own repo with its direction, its Library and its tasks. Shown as Area in the UI.                                                | business, space, workspace, domain      |
| Library        | A Satrapy's own skills, playbooks and tools, kept in that Satrapy's repo.                                                                                                                                      | shared folder                           |
| Great Library  | Skills, playbooks and tools used by two or more Satrapies, kept once and available to every Satrapy.                                                                                                           | shared layer, global skills             |
| Wight mode     | The continuous mode in which the Promachos keeps working one Satrapy on its own, nudged by continue until its time box or quota line runs out.                                                                 | Deep Work, autopilot, always-on loop    |
| Spectrum       | A disposable thread where Drafters of several Colors talk with each other, either as a moderated council or freely.                                                                                            | room, channel, group chat               |
| Color          | One harness, model and effort used together, such as Claude Opus 5.5 at high effort. A Drafter runs on one Color.                                                                                              | model config, route                     |
| Drafter        | An agent working for the user on one harness and model, such as one the Promachos hands work to.                                                                                                               | worker, subagent, helper, bot           |
| Prism          | The router: picks the model, harness and effort for each delegated role and falls back when capacity runs out.                                                                                                 | Model Router                            |
| Toolbox        | Planned name for the user's own future harness.                                                                                                                                                                |                                         |
| T3 Code        | The upstream project this fork tracks (`pingdotgg/t3code`) and anything built from it. Short form: T3.                                                                                                         |                                         |
